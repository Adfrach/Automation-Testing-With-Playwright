# Test Plan - Performance (Manage Reviews) - E2E

**Feature Number**: 08 | **Mode**: E2E | **Sumber**: `PRD/prd-08-performance.md`

## Skenario

### TC-01 Buka halaman Employee Reviews via menu Performance @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Performance" di sidebar
Then URL menjadi /performance/searchEvaluatePerformanceReview
And heading "Employee Reviews" tampil
And filter Employee Name, Job Title, Sub Unit, Include, Review Status, From/To Date tersedia
```

### TC-02 Search tanpa filter (opsional) @smoke @regression
```gherkin
Given berada di halaman Employee Reviews tanpa mengubah filter
When klik tombol Search
Then tidak ada error dan tabel review tetap tampil
```

### TC-03 Reset filter @regression
```gherkin
Given filter Employee Name terisi teks
When klik tombol Reset
Then field kembali kosong/default
```
