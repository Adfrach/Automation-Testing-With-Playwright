# Test Plan - My Info (Personal Details) - E2E

**Feature Number**: 07 | **Mode**: E2E | **Sumber**: `PRD/prd-07-my-info.md`

## Skenario

### TC-01 Buka halaman Personal Details via menu My Info @smoke @regression
```gherkin
Given admin sudah login
When klik menu "My Info" di sidebar
Then URL menjadi /pim/viewPersonalDetails/empNumber/<id>
And heading "Personal Details" tampil
And field First/Middle/Last Name, Employee Id, Nationality, Marital Status, Date of Birth, Gender tersedia
And tombol Save dan section Attachments tampil
```

### TC-02 Tab navigasi lengkap (10 tab) @regression
```gherkin
Given berada di halaman Personal Details
Then tab Personal Details, Contact Details, Emergency Contacts, Dependents, Immigration, Job, Salary, Report-to, Qualifications, Memberships tampil
```

### TC-03 Validasi Save tanpa First Name (negative) @regression
```gherkin
Given berada di halaman Personal Details dengan First Name dikosongkan
When klik tombol Save
Then pesan "Required" tampil pada field First Name
```
