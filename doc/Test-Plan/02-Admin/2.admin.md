# Test Plan - Admin (User Management) - E2E

## Skenario

### TC-01 Buka halaman System Users via menu Admin @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Admin" di sidebar
Then URL menjadi /admin/viewSystemUsers
And heading "System Users" tampil
And tabel berkolom Username, User Role, Employee Name, Status, Actions tampil
And counter "(N) Records Found" tampil dengan N > 0
```

### TC-02 Search user by username valid @smoke @regression
```gherkin
Given berada di halaman System Users
When isi filter Username = "Admin"
And klik tombol Search
Then counter menampilkan "(1) Record Found"
And tabel hanya menampilkan baris user "Admin" (Cole Palmer, role Admin, Enabled)
```

### TC-03 Search user tidak ditemukan @regression
```gherkin
Given berada di halaman System Users
When isi filter Username = "NoSuchUserXYZ"
And klik tombol Search
Then tabel tidak menampilkan baris data
```

### TC-04 Reset filter @regression
```gherkin
Given filter Username terisi "Admin" dan hasil pencarian aktif
When klik tombol Reset
Then field filter kembali kosong
And daftar user lengkap tampil kembali
```

### TC-05 Validasi elemen UI form Add User @smoke @regression
```gherkin
Given berada di halaman System Users
When klik tombol Add
Then URL menjadi /admin/saveSystemUser
And heading "Add User" tampil
And field wajib tampil: User Role*, Employee Name*, Status*, Username*, Password*, Confirm Password*
And hint password tampil
And tombol Cancel & Save tersedia
```

### TC-06 Submit Add User kosong (negative) @regression
```gherkin
Given berada di form Add User tanpa mengisi apapun
When klik Save
Then pesan "Required" tampil pada setiap field wajib
And tetap berada di halaman Add User
```

### TC-07 Password mismatch (negative) @regression
```gherkin
Given berada di form Add User
When isi Password = "Test@1234" dan Confirm Password = "Test@9999"
And klik Save
Then pesan "Passwords do not match" tampil
```

### TC-08 Tambah user baru valid (happy flow) @smoke @regression
```gherkin
Given berada di form Add User
When pilih User Role = "ESS"
And isi Employee Name dengan hint employee yang ada
And pilih Status = "Enabled"
And isi Username unik & Password = Confirm Password yang valid
And klik Save
Then redirect ke /admin/viewSystemUsers
And toast sukses "Successfully Saved" tampil
And user baru muncul di daftar
```
