# Test Plan - PIM (Employee Management) - E2E

## Skenario

### TC-01 Buka halaman Employee List via menu PIM @smoke @regression
```gherkin
Given admin sudah login
When klik menu "PIM" di sidebar
Then URL menjadi /pim/viewEmployeeList
And heading "Employee Information" tampil
And tabel berkolom Id, First (& Middle) Name, Last Name, Job Title, Employment Status, Sub Unit, Supervisor, Actions
And counter "(N) Records Found" tampil dengan N > 0
```

### TC-02 Search employee by name valid @smoke @regression
```gherkin
Given berada di halaman Employee List
When isi filter Employee Name = "Amelia"
And klik tombol Search
Then counter menampilkan "(1) Record Found"
And tabel hanya menampilkan baris karyawan "Amelia"
```

### TC-03 Search employee tidak ditemukan @regression
```gherkin
Given berada di halaman Employee List
When isi filter Employee Name = "NoSuchPersonXYZ"
And klik tombol Search
Then tabel tidak menampilkan baris data
```

### TC-04 Reset filter @regression
```gherkin
Given filter Employee Name terisi dan hasil pencarian aktif
When klik tombol Reset
Then field filter kembali kosong
And daftar lengkap karyawan tampil kembali
```

### TC-05 Validasi elemen UI form Add Employee @smoke @regression
```gherkin
Given berada di halaman Employee List
When klik tombol Add
Then URL menjadi /pim/addEmployee
And heading "Add Employee" tampil
And field First Name, Middle Name, Last Name tampil
And Employee Id terisi otomatis (tidak kosong)
And toggle "Create Login Details" tersedia
And hint upload foto tampil
And tombol Cancel & Save tersedia
```

### TC-06 Submit Add Employee kosong (negative) @regression
```gherkin
Given berada di form Add Employee tanpa mengisi apapun
When klik Save
Then pesan "Required" tampil pada First Name & Last Name
And tetap berada di halaman Add Employee
```

### TC-07 Toggle Create Login Details @smoke @regression
```gherkin
Given berada di form Add Employee
When klik toggle "Create Login Details"
Then field Username*, Status*, Password* tampil
```

### TC-08 Tambah employee baru valid (happy flow) @smoke @regression
```gherkin
Given berada di form Add Employee
When isi First Name & Last Name unik yang valid
And klik Save
Then redirect ke halaman detail karyawan (Personal Details)
And nama karyawan baru tampil di header profil
```
