# Test Plan - Recruitment (Candidates) - E2E

**Feature Number**: 06 | **Mode**: E2E | **Sumber**: `PRD/prd-06-recruitment.md`

## Skenario

### TC-01 Buka halaman Candidates via menu Recruitment @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Recruitment" di sidebar
Then URL menjadi /recruitment/viewCandidates
And heading "Candidates" tampil
And tombol Add tersedia
And filter Job Title, Vacancy, Hiring Manager, Status, Candidate Name, Keywords, Date of Application, Method of Application tampil
```

### TC-02 Search tanpa filter (opsional) @smoke @regression
```gherkin
Given berada di halaman Candidates tanpa filter
When klik tombol Search
Then tidak ada error dan tabel kandidat tetap tampil
```

### TC-03 Reset filter @regression
```gherkin
Given filter Candidate Name terisi teks
When klik tombol Reset
Then field kembali kosong/default
```
