# Test Plan - Time (Timesheets) - E2E

**Feature Number**: 05 | **Mode**: E2E | **Sumber**: `PRD/prd-05-time.md`

## Skenario

### TC-01 Buka halaman View Employee Timesheet via menu Time @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Time" di sidebar
Then URL menjadi /time/viewEmployeeTimesheet
And heading "Select Employee" tampil
And field Employee Name (placeholder "Type for hints...") tampil
And tombol View tersedia
And section "Timesheets Pending Action" tampil
```

### TC-02 Validasi View tanpa Employee Name (negative) @regression
```gherkin
Given berada di halaman View Employee Timesheet tanpa mengisi Employee Name
When klik tombol View
Then pesan "Required" tampil pada field Employee Name
```

### TC-03 View timesheet karyawan valid @smoke @regression
```gherkin
Given berada di halaman View Employee Timesheet
When isi Employee Name dengan hint karyawan demo lalu pilih opsi autocomplete
And klik tombol View
Then halaman timesheet karyawan tampil (heading berisi nama karyawan / periode)
```
