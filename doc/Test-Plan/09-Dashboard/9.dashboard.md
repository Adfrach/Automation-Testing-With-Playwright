# Test Plan - Dashboard - E2E

**Feature Number**: 09 | **Mode**: E2E | **Sumber**: `PRD/prd-09-dashboard.md`

## Skenario

### TC-01 Buka halaman Dashboard @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Dashboard" di sidebar
Then URL menjadi /dashboard/index
And heading "Dashboard" tampil
And widget Time at Work, My Actions, Quick Launch, Buzz Latest Posts, Employees on Leave Today tampil
```

### TC-02 Quick Launch Assign Leave navigasi benar @regression
```gherkin
Given berada di halaman Dashboard
When klik tombol "Assign Leave" pada widget Quick Launch
Then URL menjadi /leave/assignLeave
```

### TC-03 Empty state Employees on Leave Today (opsional) @regression
```gherkin
Given berada di halaman Dashboard
When tidak ada karyawan cuti hari ini
Then pesan "No Employees are on Leave Today" ATAU daftar karyawan cuti tampil (dinamis)
```
