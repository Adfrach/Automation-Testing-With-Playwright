# Test Plan E2E - 01 Login (OrangeHRM)

> **Fitur:** Login / Authentication
> **Mode:** E2E (UI)
> **Environment:** development
> **Base URL:** `https://opensource-demo.orangehrmlive.com`
> **Total Test Cases:** 8
> **Tagging:** @smoke / @regression

---

## Ringkasan

Fitur Login adalah gerbang utama aplikasi OrangeHRM. Pengguna memasukkan Username & Password lalu klik Login. Berhasil → redirect ke Dashboard; gagal kredensial & field kosong → pesan validasi yang sesuai. Bagian API tersedia di `1.login-api.md`.

---

## Skenario Test

### TC-01 - Login berhasil dengan kredensial valid — @smoke @regression
**Gherkin:**
- Given user berada di halaman login
- When user mengisi `Username=Admin` dan `Password=admin123`
- And user klik `Login`
- Then user diarahkan ke Dashboard

**Expected step-by-step:**
1. Buka `/web/index.php/auth/login` → tampil form login.
2. Isi Username `Admin`.
3. Isi Password `admin123`.
4. Klik Login.
5. URL berubah menjadi `/web/index.php/dashboard/index` dan heading "Dashboard" tampil.

### TC-02 - Login gagal dengan password salah — @regression
**Steps:**
1. Login dgn `Admin` / `wrongpassword`.
2. Klik Login.
3. URL tetap `/auth/login`; muncul teks "Invalid credentials".

### TC-03 - Login gagal dengan username salah — @regression
**Steps:**
1. Login `WrongUser` / `admin123`.
2. Klik Login.
3. Tetap di `/auth/login`; muncul "Invalid credentials".

### TC-04 - Login dengan username kosong — @smoke @regression
**Steps:**
1. Username kosong, Password `admin123`.
2. Klik Login.
3. Muncul teks **"Required"** di bawah field Username.

### TC-05 - Login dengan password kosong — @smoke @regression
**Steps:**
1. Username `Admin`, Password kosong.
2. Klik Login.
3. Muncul teks **"Required"** di bawah field Password.

### TC-06 - Login dengan kredensial kosong (keduanya) — @regression
**Steps:**
1. Kedua field kosong.
2. Klik Login.
3. Muncul **"Required"** di kedua field.

### TC-07 - Validasi elemen UI (halaman login) — @smoke @regression
**Steps:**
1. Buka `/web/index.php/auth/login`.
2. Pastikan terdapat: heading "Login", textbox Username, textbox Password, tombol Login.
3. Pastikan link "Forgot your password?" tampil.

### TC-08 - Klik Forgot Password navigasi ke halaman reset — @regression
**Steps:**
1. Buka `/web/index.php/auth/login`.
2. Klik link "Forgot your password?".
3. URL berubah ke halaman request reset (`requestPasswordResetCode`).
