# Test Plan - Directory - E2E

**Feature Number**: 10 | **Mode**: E2E | **Sumber**: `PRD/prd-10-directory.md`

## Skenario

### TC-01 Buka halaman Directory @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Directory" di sidebar
Then URL menjadi /directory/viewDirectory
And heading "Directory" tampil
And filter Employee Name, Job Title, Location + tombol Reset/Search tampil
And daftar karyawan dengan "(N) Records Found" tampil
```

### TC-02 Search Employee Name "Peter" @regression
```gherkin
Given berada di halaman Directory
When isi Employee Name dengan hint "Peter Mac Anderson"
And klik Search
Then hasil terfilter dan kartu karyawan Peter tampil
```

### TC-03 Search nama tidak dikenal @regression
```gherkin
Given berada di halaman Directory
When isi Employee Name dengan nama acak yang tidak ada
And klik Search
Then pesan "No Records Found" tampil
```
