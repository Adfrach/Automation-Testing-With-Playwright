## Skenario

### TC-01 Buka halaman Leave List via menu Leave @smoke @regression
```gherkin
Given admin sudah login
When klik menu "Leave" di sidebar
Then URL menjadi /leave/viewLeaveList
And heading "Leave List" tampil
And filter From Date, To Date, Show Leave with Status, Leave Type, Employee Name, Sub Unit tampil
And tombol Reset & Search tersedia
```

### TC-02 Validasi Search tanpa Status (negative) @regression
```gherkin
Given berada di halaman Leave List tanpa memilih Status
When klik tombol Search
Then pesan "Required" tampil pada field Show Leave with Status
```

### TC-03 Search leave dengan status valid @smoke @regression
```gherkin
Given berada di halaman Leave List
When pilih Status = "Pending Approval"
And isi From Date & To Date rentang tahun berjalan
And klik tombol Search
Then hasil pencarian tampil (tabel data atau "No Records Found")
```

### TC-04 Reset filter @regression
```gherkin
Given filter terisi dan pencarian pernah dijalankan
When klik tombol Reset
Then semua field filter kembali kosong/default
```

### TC-05 Halaman Apply Leave - user tanpa entitlement @smoke @regression
```gherkin
Given admin login tanpa leave entitlement
When buka menu topbar "Apply" atau URL /leave/applyLeave
Then heading "Apply Leave" tampil
And pesan "No Leave Types with Leave Balance" tampil menggantikan form
```
